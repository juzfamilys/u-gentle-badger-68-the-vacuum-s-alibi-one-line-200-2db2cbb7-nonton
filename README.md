## The line

> I didn't miss that spot. My lidar classified your sock as a hibernating animal, and my battery has a strict no-wake policy.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), one line, 123 characters, UTF-8.
